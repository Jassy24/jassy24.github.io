CSC 340 - Event Center

Reason

Traditional event platforms often feel fragmented and outdated. Event discovery is time-consuming, ticket purchases can be frustrating, and vendors struggle to manage their booths effectively. These pain points create barriers for attendees, organizers, and vendors alike, limiting their ability to fully engage with the events they care about.

Purpose

EventCenter was created as a one-stop solution for the entire event ecosystem — attendees, organizers, and vendors. The goal is to simplify how people discover events, purchase tickets, and manage event-related logistics. By centralizing these actions into a single, intuitive platform, EventCenter empowers users to participate in and contribute to events more easily, while fostering a connected and thriving community.

The Result

  • Event Discovery: with search and filter capabilities
  • Secure Ticket Purchase: through a user-friendly payment gateway
  • Vendor Booth Management: tools for bookings and payments
  • Custom User Profiles: tailored for both attendees and vendors
  • Real-time Notifications: to keep users informed of updates
  • Reviews and Ratings: that build event credibility
  • Personalized Recommendations: powered by user behavior
