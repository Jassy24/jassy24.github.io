Senior Capstone - Ideal Bet


Introduction

IdealBet is a sports betting analytics platform that combines real-time odds, historical data, and advanced algorithms to provide accurate predictions.

The System

Features include probability analysis, team/player stats, custom betting strategies, user authentication, and an AI-powered assistant. Frontend built with Next.js, Tailwind CSS, Framer Motion, and React Hooks.


The Result

A modern, data-driven platform that delivers user-friendly analytics for NBA bettors, showcasing my ability to merge technical skills with interface design.
